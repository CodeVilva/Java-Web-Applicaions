# Java Web Applications

A collection of Java web applications developed using Java EE technologies, demonstrating server-side development, database integration, authentication, and full-stack web application concepts.

## Technologies Used

- Java
- Servlets
- JSP (JavaServer Pages)
- JDBC
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- Apache Tomcat
- Maven *(for Maven-based projects)*

## Projects

### QR-Based Smart Voting System
A secure online voting system that uses QR codes for voter verification and authentication.

### Product Demand Forecasting System
A hybrid web application that combines Java web technologies with machine learning to predict product demand.

### Car Service Center Booking System
A web application for booking vehicle service appointments and managing customer records.

### Wedding Hall Booking System
An online booking platform for managing wedding hall reservations.

### Online Quiz System
A web-based quiz application with user authentication, question management, and score tracking.

## Getting Started

### Prerequisites

- Java JDK 8 or later
- Apache Tomcat
- MySQL Server
- NetBeans / IntelliJ IDEA / Eclipse
- Maven (for Maven-based projects)

### Installation

1. Clone the repository.
2. Import the desired project into your IDE.
3. Configure the MySQL database.
4. Update the database credentials if necessary.
5. Deploy the project on Apache Tomcat.
6. Run the application.
