# 🔐 Secure Lock

A secure Java desktop application that allows users to protect sensitive files through encryption and controlled access. Built using Java, Secure Lock provides a simple and reliable way to secure personal or confidential data with an intuitive interface.

---

## ✨ Features

- 🔒 Secure file encryption and decryption
- 📂 Easy file selection
- 🔑 Password-based protection
- 🛡️ AES encryption for strong security
- 💻 Simple and user-friendly interface
- ⚡ Fast file processing
- 🖥️ Cross-platform support (Windows, Linux, macOS)

---

## 🛠️ Technologies Used

- Java
- Java Swing
- Java Cryptography Extension (JCE)
- AES Encryption
- NetBeans IDE

## 🚀 Getting Started

### Prerequisites

- Java JDK 8 or later
- NetBeans IDE (Recommended)

### Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/SecureLock.git
```

2. Open the project in NetBeans.

3. Build and run the project.

---

## 📌 How It Works

1. Launch the application.
2. Select the file to secure.
3. Enter a strong password.
4. Encrypt the file.
5. To access the file later, choose the encrypted file and provide the correct password to decrypt it.
